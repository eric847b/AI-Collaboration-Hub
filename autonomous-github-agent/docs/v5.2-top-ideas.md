5. **Lean on free battle-tested tools** instead of reinventing:

   - **Ruff** (Astral) — ultra-fast Python lint/format

   - **dependency-review-action** — block vulnerable deps in PRs (free on public repos)

## Why these free tools

| Tool | Benefit vs custom code |
|------|------------------------|
| Dependabot | GitHub-native PRs for npm/pip/actions; zero maintenance |
| Ruff | Replaces flake8+isort+black; 10–100× faster |
| pre-commit | Catches secrets / YAML / style before CI burns minutes |
| dependency-review | PR-time CVE gate without running full audit yourself |

## Enable locally

```bash
pip install pre-commit ruff
pre-commit install
ruff check autonomous-github-agent --fix
```

## Wire consensus in agent.py

Near the start of `execute_one_task`:

```python
from agent_hooks import gate_with_consensus
if not gate_with_consensus(task, call_llm, profile):
    logger.info("Consensus veto — skipping automated fix")
    os.system("git checkout main 2>/dev/null || true")
    return False
```
