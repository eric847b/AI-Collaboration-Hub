# Autonomous GitHub Agent — v5.0 Nexus

## Why v5.0 (best version choice)

| Candidate | Rationale |
|-----------|-----------|
| v4.8 / v4.9 | Incremental only — understates the unification |
| **v5.0** | Clean major: problem solvers + self-heal + consensus + closed-loop + collab patterns |
| v99 (userscript style) | Theatrical; better as userscript branding than Python agent semver |

**v5.0** is the best functional result: clear major boundary, semver-friendly, aligns with “Nexus” identity from CollabHub modules.

## Inspiration from CollabHub userscripts

From `99-OmniNexus-Final` / `23-UltimateNexus`:

- Multi-provider routing (O / A / G / M)
- Multi-role consensus: Planner → Researcher → Critic → Forge → Echo
- Self-tuning learn cycles
- Exportable state

Ported into the agent as `nexus_consensus.py`.

## What v5.0 includes

1. **Unified auto-repair** (syntax, peers, lockfiles, requirements, GHA)
2. **CI Self-Heal** workflow (already on main)
3. **Security audit** (report-only)
4. **Duplicate draft PR cleanup** on every solver run
5. **Closed-loop ledger** (`auto-fix-ledger.json`) — verify fixes stick, escalate reappears
6. **Nexus consensus** — collaborative multi-role planning before high-impact edits

## Env flags

- `DRY_RUN=1` — report only
- `MAX_SOLVER_TASKS=N` — default 8
- `AGENT_OWNS_GITHUB=1` — allow PR creation
