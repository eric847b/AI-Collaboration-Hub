## Env flags

| Flag | Default | Meaning |
|------|---------|--------|
| `DRY_RUN` | 0 | Report only |
| `MAX_SOLVER_TASKS` | 8 | Cap auto-fix PRs per run |
| `MULTI_REPO` | 0 | Discover sibling repos (metadata) |
| `NEXUS_CONSENSUS` | 1 | Use multi-role consensus when LLM available |
| `AGENT_OWNS_GITHUB` | 0 | Allow PR/issue creation |

## How agent.py uses consensus

```python
from agent_nexus_bridge import consult_nexus, should_proceed

c = consult_nexus(title, body, call_llm_fn=call_llm, profile=profile)
if not should_proceed(c):
    # document / skip high-risk change
    ...
```

Import the bridge from issue/PR handlers when making non-trivial edits.
