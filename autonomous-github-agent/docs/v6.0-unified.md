# Autonomous GitHub Agent — v6.0 Unified

## Why v6.0 (highest real-world working version)

| Candidate | Rationale |
|-----------|-----------|
| v5.4 / v5.5 | Incremental only — understates the agent.py consensus integration |
| **v6.0** | Clean major: every shipped v5.x capability + consensus **inside** the main LLM task path |
| Future v7+ | Reserved for multi-repo deep clone / cross-repo PRs / agentic workflow hosts |

**v6.0** consolidates known future work that was already designed into one operational baseline:

- Consensus gate wired into `agent.py` `execute_one_task` (issue / pr_review / todo)

- Docs folded into this single source of truth

## How agent.py uses consensus (v6.0)

Near the start of `execute_one_task`:

```python
from agent_hooks import gate_with_consensus
if not gate_with_consensus(task, call_llm, profile):
    logger.info("Nexus consensus veto — skipping")
    return False
```
