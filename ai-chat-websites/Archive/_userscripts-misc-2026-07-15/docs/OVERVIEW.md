# AI Chat Websites - Overview

## Project Summary

AI Chat Websites is a comprehensive collection of userscripts for AI chat platforms, organized into logical categories for easy management and use. The project provides advanced features, enterprise-grade security, and cutting-edge AI integration.

## Key Features

- **40+ specialized modules** covering core utilities, automation, and advanced features
- **Modular build system** with validation, testing, and bundling
- **AI-powered automation** with machine learning integration (TensorFlow.js)
- **Advanced security** with threat detection and behavioral analysis
- **Modular architecture** for easy maintenance and expansion

## Architecture

The project follows a modular architecture with clear separation of concerns:

- **Core System**: Hub management (`00-hub.user.js`) and configuration (`settings-ui.js`)
- **Modules**: Specialized functionality in `Modules/` directory
- **Build System**: Automated building, testing, and validation in `scripts/`
- **Documentation**: Comprehensive guides in `docs/`

## Technology Stack

- **JavaScript**: Primary development language
- **npm**: Package management and dependency handling
- **Jest**: Testing framework
- **ESLint**: Code quality
- **Custom bundlers**: Build and bundling scripts
