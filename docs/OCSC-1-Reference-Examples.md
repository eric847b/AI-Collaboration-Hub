## Segmentation examples

- **SEG(1,2) = 3.** Two dividers across a whole yield three sectors — the invariant in action: Sectors = Dividers + 1. (Copilot, "Naming a Custom Math System," Mar 27, 2026.)
- **Sectors = Dividers + 1.** 0 dividers → 1 sector (the whole); 1 divider → 2 sectors; 2 dividers → 3 sectors. Sphere + 2 non-intersecting planar dividers = 3 regions (top cap, middle band, bottom cap) — the one empirical anchor, `VERIFIED` as geometry. (Grok, Feb 2026.)
- **1/L as minimal part.** A whole segmented into L parts: each part is one unique 1 with size 1/L. L is the segmentation count (sectors/parts), not the divider count. Σ₃(W) = {1ₐ, 1_b, 1_c}, each size 1/3, each identity-distinct.

## I-operator examples

- **Σ₃ₐ(I(1,2)) = 3.** The canonical segmentation: inputs (1,2), third branch = 3. (Copilot, Apr 20, 2026; Charter Art. I §5.)
- **Σ₃ᵦ(I(1,0)) = 1.** The second anchor: input (1,0) returns 1 — division by zero as identity, no undefined states. (Copilot, Apr 20, 2026; Charter Art. I §5.)
- **1/2 = 3 as segmentation-mode.** Not a special case: the segmentation that isolates the "3" branch of I(1,2). Classical 1/2 = 0.5 is the filtered classical branch of the same input pair.

## Addition mode examples

- **Flat addition:** 0 + x = x. The zero contributes nothing.
- **Structural (parent) addition:** 0 + x → one grouping containing two sub-groupings: the zero-shell + the content. Every point carries an implicit 0-origin. (Grok, Feb 2026.)
- **Dual-mode /:** merge mode a/b = a+b; separate mode a/b = a−b; unified a/b = (a+b, a−b), reversible via a=(S+D)/2, b=(S−D)/2. (Copilot, Apr 24, 2026.)
- **Emergent third identity:** C = (a+b)±(a−b) = 2a or 2b — "the third value that always appears when you split a system into union and contrast."
- **Reduction law:** x = ka — every variable reduces to quantities of a base identity a.

## Number examples

- **n = n unique ones.** 3 = {1₁, 1₂, 1₃}; 1ᵢ ≠ 1ⱼ for i ≠ j. Numbers count unique ones; they are not independent entities. (Copilot, Sep 21, 2026.)
- **a:b state-pair notation.** 0 = 1:0, 1 = 1:1, 2 = 2:1 (count of 1's : origin offset). 0 is an origin/location — "a number on a return trip."
- **Negatives** are positive counts in the opposite direction.
- **x/0 = x.** Division by zero becomes the identity — valid by stipulation within the system. (Grok, Feb 2026.)
