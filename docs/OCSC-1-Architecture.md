## 1. Core operators

- **I-operator (I):** the only operator. Every mathematical act is I; all classical operators are segmentation-modes of I (merge, inversion, binding, relation, stacking, partition). I(state₁, state₂) returns the full inclusive state-space; classical math returns one branch.
- **Segmentation (Σ):** the only transformation. Σ₃ is the 3-branch form with anchor laws Σ₃ₐ(I(1,2)) = 3 and Σ₃ᵦ(I(1,0)) = 1.
- **Addition modes:** flat addition (0+x = x) vs. structural/parent addition (0+x → a grouping containing the zero-shell + the content).
- **Sector Law:** Sectors = Dividers + 1. SEG(1,2) = 3.
- **D (Declaration operator):** D(S) := S* — fixes meaning at first writing. D(D(S)) = ∅.

## 4. Flow of reasoning

How a collaborator processes a claim:

1. **Parse** the claim into glossary terms.
2. **Tag** it `DECLARED` or `DERIVED`.
3. **Check** DECLARED lines against the charter with provenance.
4. **Verify** DERIVED lines via `docs/OCSC-1-Verification-Protocol.md`.
5. **Scan** for contradictions with any DECLARED line — a contradiction rejects the claim, never the given.
6. **Report** with verification status (`VERIFIED` / `FRAMEWORK-INTERNAL` / `UNVERIFIED`).
