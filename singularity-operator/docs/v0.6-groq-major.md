# v0.6 — Major: Groq SDK ≥1.6 + restored router

## Why this is the next major

1. **`groq_wrapper.py` was missing** but imported by `__init__`, CLI, SelfImprover, EverythingDB → package was broken at import time.
2. Dependabot PRs **#155 / #169** raised `groq` from `>=0.4.0` → `>=1.6.0` (current stable line).
3. Wiring both restores the Singularity Operator brain and lands the major dependency jump safely.

## Public API

```python
from singularity_operator import call_ai, get_provider_status, GroqWrapper

r = call_ai("Hello", provider="groq")
print(r["response"], r["model"], r["latency_s"])

print(get_provider_status())
gw = GroqWrapper()
print(gw.call("ping"))
print(gw.get_metrics())
```

## Env

- `GROQ_API_KEY` (required for live calls)
- `GROQ_MODEL` (optional, default `llama-3.3-70b-versatile`)

## Offline behavior

Without a key or package, `call_ai` returns a structured offline-fallback dict so SelfImprover / DB still run in CI.
